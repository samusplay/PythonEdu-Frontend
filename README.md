# 🎓 PythonEDU - Frontend UI in React

**PythonEDU** is an online bootcamp platform designed to help people learn Python through practical, real-world exercises.

This repository contains the **frontend interface**, built with **React** and styled using **Tailwind CSS**, which interacts with a Django REST API backend.

I am building this project not only to create an educational platform but also as part of my journey to improve my skills in modern frontend development.

---

## 🚀 Technologies Used

- ⚛️ React (Vite)
- 🎨 Tailwind CSS
- 🌐 Axios (for API consumption)
- 🧩 React Router
- 🔧 ESLint + Prettier (optional, for code quality)
- 📁 Modular component structure

---

## 🎯 Project Vision

PythonEDU aims to become a powerful learning tool for beginner and intermediate Python learners.  
This frontend is part of a full-stack application that will deliver courses, track student progress, and provide interactive coding content.

This project is also part of my personal portfolio and learning process as a full-stack developer.

---

## 🧪 Features

- Fully responsive UI with Tailwind CSS
- API integration with Django REST Framework
- Reusable components and clean file structure
- Basic routing and page organization
- Ready to scale with backend services
